# Términos del Dominio

- `opticas`: tabla central que relaciona los diferentes módulos y permite la gestión de varias ópticas.
- `expedientes`: módulo para gestionar los registros de los clientes.
- `pacientes`: información sobre los pacientes.
- `inventario`: control de los productos disponibles.
- `punto de venta`: solución para realizar transacciones.
- `citas`: gestión de citas con clientes.
- `promociones`: manejo de ofertas y descuentos.
- `paquetes`: combinación de productos o servicios.
- `reparaciones`: seguimiento de servicios de reparación.
- `usuarios`: acceso y autenticación de usuarios.
- `sitio web público`: plataforma para promover servicios.
